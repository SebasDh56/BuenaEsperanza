# Configuración pública generada

`runtime-config.js` se crea automáticamente dentro de `dist/js/config/` durante
`npm run build`. Toma `SUPABASE_URL` y `SUPABASE_PUBLISHABLE_KEY` del entorno o
del archivo local `.env`.

No agregues aquí una clave secreta, `service_role` ni una contraseña de
PostgreSQL.
