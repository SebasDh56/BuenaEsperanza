# La Buena Esperanza de Guachalá — HTML y CSS

Frontend estático construido desde cero, sin WordPress ni dependencias externas.

## Estructura

```text
la-buena-esperanza-html-css/
├── index.html
├── css/
│   └── styles.css
└── assets/
    ├── icons/
    └── images/
```

## Cómo abrirlo

1. Descomprime el ZIP.
2. Abre `index.html` con Chrome, Edge o Firefox.
3. Para trabajar mejor, abre la carpeta en Visual Studio Code.
4. Opcional: instala la extensión **Live Server** y pulsa **Go Live**.

## Qué modificar primero

- Textos y enlaces: `index.html`.
- Colores globales: variables al inicio de `css/styles.css`.
- Fotografías: reemplaza los SVG de `assets/images/` por JPG, PNG o WebP manteniendo el nombre, o modifica sus rutas en el HTML/CSS.
- Correo y teléfono: reemplaza los valores de ejemplo.

## Próxima evolución

Cuando la estructura esté aprobada se puede separar en componentes y migrar a:

- JavaScript modular.
- React o Next.js.
- Un CMS headless.
- WordPress como backend de contenidos.
